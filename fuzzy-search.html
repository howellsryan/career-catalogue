Recover the occupation, exclude the distraction

For the fixed query plumbr and candidates plumber and plumper, choose the smallest threshold that accepts the occupation and excludes the unrelated word. This exercise uses those fixed words, even if you change the lab inputs.

The worked example

plumbr → plumber: insert e before the last letter. Distance 1.

plumbr → plumper: replace b with p, then insert e. Distance 2.

At threshold 0 neither matches. At threshold 1 only plumber matches. At threshold 2 both match, although plumper is not the trade the person wanted. The threshold cannot infer that intent.

Before adopting fuzzy search, collect real misspellings and confusing near-matches from your own domain. Check both the useful results you recovered and the irrelevant results you introduced.

Inspect the algorithm and its edge cases

This is the same two-row dynamic-programming recurrence used by the lab. Inputs are trimmed, lowercased and normalized to Unicode NFC before comparison. Accents remain significant; each Unicode code point counts as a character.

function distance(left, right) {
  const a = Array.from(left), b = Array.from(right);
  let previous = Array.from({ length: b.length + 1 }, (_, j) => j);
  for (let i = 1; i <= a.length; i++) {
    const current = [i];
    for (let j = 1; j <= b.length; j++) {
      current[j] = Math.min(
        current[j - 1] + 1,                    // insert
        previous[j] + 1,                       // delete
        previous[j - 1] + (a[i - 1] === b[j - 1] ? 0 : 1)
      );                                       // match or substitute
    }
    previous = current;
  }
  return previous[b.length];
}

Time grows with the product of the string lengths. Two rows keep memory proportional to the candidate length. The lab validates its input limits before computing and compares at most 50 candidates of 64 characters.
